# 访问子系统 · 约束

行为、开关和 health 的口径见 [design.md](design.md)。术语与规则见 [design.md](design.md#模型与术语)。本文只写边界。

## 隐私

- 订阅地址、机场名、凭据、密钥、节点名、端口、控制器、内网段：不进主仓库，不进跟踪文档，不进轮次档案。
- 地址与密钥只存在 `run/` 的 0600 文件。命令与日志不打印。文档写「运行时读取」。
- 操作者自己的终端可以显示组名和延迟。这些输出不写入档案。
- 回环与私网的具体写法由代码在运行时生成，不写进文档。

## 不入主仓库

- 脚本、命令、库、测试、文档都在本目录，只进本地 git（无远端）。
- 主仓库的忽略文件不出现本子系统名称。主仓库不跟踪本目录，靠用户级忽略。
- 本地 git 忽略 `run/`。禁止把该目录加进提交。
- 跟踪文档若引用，只写名称、一行说明、纯文本路径，不用 Markdown 链接。
- 只服务本机。要上第二台机器，需另一次拍板，不把本目录推进公开仓库。

## 回滚

系统里一旦装过，按这个顺序撤：

1. `systemctl --user disable --now` 停掉服务和刷新定时器。还没安装就跳过。
2. 删除 `run/`。地址、密钥、配置、备份和开关都在这里。开关删除后，登录脚本不再导出代理变量或桌面标识。
3. 不改 shell 里现有的 `setproxy`。
4. 主仓库没有本子系统的提交，不用反向删除。本地 git 是否保留由操作者决定，默认留代码和文档。

## 明确不做

- 不改其它工具的命令，不用包装器占名。
- 不读其它代理程序的配置或数据目录。
- 不做 TUN、多条订阅、登录前代理、跨机器部署。未启用 TUN 之前，不得写成对其它工具已经无感。
- 透明性、三层开关和 health 的细节不在这里复述。
