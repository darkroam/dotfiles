# 访问子系统 · 约束与限制

> 状态：已实现并落地（2026-10-20）。默认值、子命令、退出码只以 `design.md` 为准。

## 隐私

- 订阅地址、机场名、凭据、密钥、节点名、端口、控制器、内网段：不进主仓库，不进跟踪文档，不进轮次新段落。
- 地址与密钥只存在 `run/` 的 0600 文件。命令与日志不打印。文档写「运行时读取」。
- `groups` / `test` 可以在操作者自己的终端显示组名和延迟，不写入档案。
- 回环与私网的具体网段由脚本在运行时生成，不写进文档。本树 git 若未来接远端，先脱敏 docs/。

## 不入主仓库

- 脚本、命令、库、测试、文档都在 `~/.local/lib/access/`，只进本目录的本地 git（无远端）。
- 主仓库 `.gitignore` 不出现本子系统名称。未跟踪靠 `~/.config/git/ignore` 里已有的 `.local/lib/access/`。
- 本地 git 忽略 `run/`。禁止把该目录加进提交。
- 跟踪文档引用已合并。引用只是名称、一行说明、纯文本路径 `~/.local/lib/access/docs/`。不用 Markdown 链接。
- v1 只服务本机。因此「效果对等」先不覆盖本子系统；要上第二台机器，需另一次拍板，而不是把敏感文件推进公开仓库。

## 透明性

- 不改其它工具的命令，不用包装器占名，不新增会挡住 `/usr/bin/proxy` 的函数。
- v1 不导出代理变量。现有 `setproxy` 保持原样，不算本子系统的接口。
- 未启用 TUN 之前，不得在文档或状态里写成「对其它工具已经透明」。

## 运行边界

- 不读 Verge 的配置或数据目录。
- 用户服务只在登录会话内。开机后、登录前要代理，属于另一次授权（lingering），v1 不做。
- 系统单元与 12h 定时刷新已安装并 enable（2026-10-20 授权）。
- 健康通过不等于节点可用。节点要看 `axs node test`。

## 回滚

系统里一旦装过本子系统，按这个顺序撤：

1. `systemctl --user disable --now` 停掉服务和刷新定时器（还没安装就跳过）。
2. 删 `~/.local/lib/access/run/`（地址、密钥、配置、备份都在这里）。
3. 不改 shell 里现有的 `setproxy`。
4. 主仓库没有对应提交，不用做反向删除。本地 git 仓库是否保留，由操作者决定，默认保留代码与文档。
