## 定位

自建订阅 + mihomo 内核的**网络访问控制子系统**：以命令行工具提供优雅便捷的启停、
订阅获取与刷新、节点连通性/速度测试、域名级转发规则管理；对其它工具**透明**——
不改变其它工具自身用法，也不需要它们感知代理存在。

**不依赖 Clash Verge Rev**：订阅地址由用户提供，本项目自行获取代理信息。

## 系统等级

与「显示控制子系统」「安装子系统」平行的第三个子系统（先证后名：验证基线成立前，
跟踪文档引用写作「访问子系统（孵化中）」）。

## 目录结构（本目录）

- `bin/`：命令与包装器
- `lib/`：共享库/函数
- `tests/`：测试（TDD；每个 bug 必须落成测试）
- `docs/`：子系统文档（本文件、`design.md`、`constraints.md`、`roadmap.md`）

  **主仓库 `.gitignore` 不出现本子系统任何名称**）；

- 跟踪文档中只允许：「访问子系统」名称 + 一行说明 + **纯文本路径**（非超链接）。
